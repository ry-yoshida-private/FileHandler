# tests

## Overview

Pytest suite for `file_handler`, `txt_writer`, and `xml_handler`.

## Components

| File | Role |
|------|------|
| [test_file_handler.py](test_file_handler.py) | `FileHandler` and `FileType` round-trip and error cases |
| [test_txt_writer.py](test_txt_writer.py) | `TxtWriter` write modes and context manager |
| [test_xml_handler.py](test_xml_handler.py) | `XMLHandler` tag lookup and nested traversal |
| [test_package_init.py](test_package_init.py) | Public API exports for each package |
